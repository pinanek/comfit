# Rust API references

Rust API documentation is hosted on [docs.rs](https://docs.rs/). Choose a crate to browse its types, functions, modules, and examples.

- [comfit](https://docs.rs/comfit/latest/comfit/): native highlighting with bundled or custom grammars.
- [comfit-core](https://docs.rs/comfit-core/latest/comfit_core/): the shared highlighting engine and rendering APIs.
- [comfit-grammars](https://docs.rs/comfit-grammars/latest/comfit_grammars/): bundled parsers and queries.
- [comfit-themes](https://docs.rs/comfit-themes/latest/comfit_themes/): bundled themes and VS Code theme conversion.

For installation and usage, start with [Rust](../getting-started/rust.md).
