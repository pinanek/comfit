# HTML and CSS

Comfit renders source code as an escaped HTML fragment. The default structure is `<pre><code>`, with a `span` around each line. Choose how the fragment represents token styles:

| Mode      | Use it when                                           | What you supply                                               |
| --------- | ----------------------------------------------------- | ------------------------------------------------------------- |
| Inline    | You want theme colors in the returned HTML.           | A bundled theme ID or theme object, depending on the package. |
| Classes   | You want a shared stylesheet.                         | CSS rules for capture classes, or an `@comfit/css` theme.     |
| Variables | You want your application's CSS to define the colors. | `--comfit-*` CSS variables.                                   |

The default is classes in the libraries and inline styles in the CLI. None of these modes sets your font, padding, or line-number layout.

## Inline styles

Embed theme colors in the returned fragment.

<CodeTabs label="Inline styles API">
<CodeTab label="Node.js">

```javascript
import { renderHtml, RenderHtmlConfig, RenderHtmlStyle } from "@comfit/node";

const config = new RenderHtmlConfig();
config.style = RenderHtmlStyle.Inline;

const html = renderHtml(
  "const answer = 42;",
  "javascript",
  "catppuccin-mocha",
  config,
);
```

</CodeTab>
<CodeTab label="Browser">

Use an [initialized browser highlighter](../getting-started/browser.md) with JavaScript loaded. Inline output takes a [theme object](themes.md#custom-colors-in-the-browser), not a bundled theme ID.

```typescript
const html = highlighter.renderHtml("const answer = 42;", "javascript", {
  style: "inline",
  theme: {
    default: { fg: "#cdd6f4", bg: "#1e1e2e" },
    styles: {
      keyword: { fg: "#cba6f7" },
      number: { fg: "#fab387" },
    },
  },
});
```

</CodeTab>
<CodeTab label="Rust">

Enable the `javascript` and `render-html` features on `comfit`. Also enable `catppuccin-mocha` on `comfit-themes`.

```rust
let mut highlighter = comfit::Highlighter::new()?;
let highlighted = highlighter.highlight(
    "const answer = 42;",
    "javascript",
    &comfit::HighlightConfig::default(),
)?;
let config = comfit::RenderHtmlConfig {
    style: comfit::RenderHtmlStyle::Inline,
    ..Default::default()
};
let html = highlighted.render_html(comfit_themes::catppuccin_mocha::theme(), &config);
```

</CodeTab>
<CodeTab label="Python">

```python
import comfit

config = comfit.RenderHtmlConfig(style=comfit.RenderHtmlStyle.Inline)
html = comfit.render_html(
    "const answer = 42;", "javascript", "catppuccin-mocha", config
)
```

</CodeTab>
<CodeTab label="rehype">

Add this configuration to your framework's `rehypePlugins`. See the [Markdown and MDX](markdown.md) to set up a pipeline.

```javascript
import rehypeComfit from "@comfit/rehype";

const rehypePlugins = [
  [rehypeComfit, { style: "inline", theme: "catppuccin-mocha" }],
];
```

</CodeTab>
<CodeTab label="Command line">

```sh
comfit html main.js --theme catppuccin-mocha --style inline
```

</CodeTab>
</CodeTabs>

## Classes

Use class-based output when several code blocks should share a stylesheet instead of embedding colors in every fragment. `@comfit/css` styles HTML generated by any Comfit package.

This example uses Catppuccin Mocha. The [theme catalog](themes.md#bundled-themes) lists the other stylesheets and their matching outer classes.

### Install a stylesheet

<CodeTabs label="Package manager">
<CodeTab label="pnpm">

```sh
pnpm add @comfit/css
```

</CodeTab>
<CodeTab label="npm">

```sh
npm install @comfit/css
```

</CodeTab>
<CodeTab label="bun">

```sh
bun add @comfit/css
```

</CodeTab>
</CodeTabs>

### Load a theme

Load the stylesheet on the web page that displays the generated HTML, regardless of which Comfit package renders it.

<CodeTabs label="Stylesheet loading">
<CodeTab label="Bundler">

Import the stylesheet in your frontend entry point with a build tool that supports CSS imports.

```javascript
import "@comfit/css/catppuccin-mocha.css";
```

</CodeTab>
<CodeTab label="HTML">

For a page without a bundler, use a `link` element.

```html
<link
  rel="stylesheet"
  href="https://esm.sh/@comfit/css@0.1.0/dist/catppuccin-mocha.css"
>
```

</CodeTab>
</CodeTabs>

### Match the HTML class

Generate a fragment with the matching outer class:

<CodeTabs label="Class output API">
<CodeTab label="Node.js">

```javascript
import { renderHtmlClasses, RenderHtmlConfig } from "@comfit/node";

const config = new RenderHtmlConfig();
config.preClass = "comfit-catppuccin-mocha";

const html = renderHtmlClasses("const answer = 42;", "javascript", config);
```

</CodeTab>
<CodeTab label="Browser">

Use an [initialized browser highlighter](../getting-started/browser.md) with JavaScript loaded.

```typescript
import "@comfit/css/catppuccin-mocha.css";

const html = highlighter.renderHtml("const answer = 42;", "javascript", {
  style: "class",
  preClass: "comfit-catppuccin-mocha",
});
```

</CodeTab>
<CodeTab label="Rust">

Enable the `javascript` and `render-html` features on `comfit`.

```rust
let mut highlighter = comfit::Highlighter::new()?;
let highlighted = highlighter.highlight(
    "const answer = 42;",
    "javascript",
    &comfit::HighlightConfig::default(),
)?;
let config = comfit::RenderHtmlConfig {
    pre_class: Some("comfit-catppuccin-mocha".into()),
    ..Default::default()
};
let html = highlighted.render_html_classes(&config);
```

</CodeTab>
<CodeTab label="Python">

Pass a valid bundled theme ID even in class mode.

```python
import comfit

config = comfit.RenderHtmlConfig(
    style=comfit.RenderHtmlStyle.Class,
    pre_class="comfit-catppuccin-mocha",
)
html = comfit.render_html(
    "const answer = 42;", "javascript", "catppuccin-mocha", config
)
```

</CodeTab>
<CodeTab label="rehype">

Add this configuration to your framework's `rehypePlugins`. See the [Markdown and MDX](markdown.md) to set up a pipeline.

```javascript
import rehypeComfit from "@comfit/rehype";

const rehypePlugins = [
  [rehypeComfit, { style: "class", preClass: "comfit-catppuccin-mocha" }],
];
```

</CodeTab>
<CodeTab label="Command line">

```sh
comfit html main.js --theme catppuccin-mocha --style class \
  --pre-class comfit-catppuccin-mocha
```

</CodeTab>
</CodeTabs>

The stylesheet's scope must match the outer `pre` class: `catppuccin-mocha.css` expects `comfit-catppuccin-mocha`. You can serve the stylesheet through an HTML `link` element instead of importing it.

A `function.call` capture produces both `function` and `function-call` classes. Lines have `line` and, when selected, `line-highlight` classes. Brackets can have `rainbow` and `rainbow-N` classes.

The class-prefix option changes these names. Bundled CSS expects no prefix. A custom prefix needs a matching stylesheet.

## CSS variables

Render CSS variable references instead of theme colors.

<CodeTabs label="CSS variables API">
<CodeTab label="Node.js">

```javascript
import {
  renderHtmlClasses,
  RenderHtmlConfig,
  RenderHtmlStyle,
} from "@comfit/node";

const config = new RenderHtmlConfig();
config.style = RenderHtmlStyle.Variables;
config.preClass = "code-block";

const html = renderHtmlClasses("const answer = 42;", "javascript", config);
```

</CodeTab>
<CodeTab label="Browser">

Use an [initialized browser highlighter](../getting-started/browser.md) with JavaScript loaded.

```typescript
const html = highlighter.renderHtml("const answer = 42;", "javascript", {
  style: "variables",
  preClass: "code-block",
});
```

</CodeTab>
<CodeTab label="Rust">

Enable the `javascript` and `render-html` features on `comfit`.

```rust
let mut highlighter = comfit::Highlighter::new()?;
let highlighted = highlighter.highlight(
    "const answer = 42;",
    "javascript",
    &comfit::HighlightConfig::default(),
)?;
let config = comfit::RenderHtmlConfig {
    style: comfit::RenderHtmlStyle::Variables,
    pre_class: Some("code-block".into()),
    ..Default::default()
};
let html = highlighted.render_html_classes(&config);
```

</CodeTab>
<CodeTab label="Python">

A valid theme ID is required, although variable mode does not use its palette.

```python
import comfit

config = comfit.RenderHtmlConfig(
    style=comfit.RenderHtmlStyle.Variables,
    pre_class="code-block",
)
html = comfit.render_html(
    "const answer = 42;", "javascript", "catppuccin-mocha", config
)
```

</CodeTab>
<CodeTab label="rehype">

Add this configuration to your framework's `rehypePlugins`. See the [Markdown and MDX](markdown.md) to set up a pipeline.

```javascript
import rehypeComfit from "@comfit/rehype";

const rehypePlugins = [
  [rehypeComfit, { style: "variables", preClass: "code-block" }],
];
```

</CodeTab>
<CodeTab label="Command line">

A valid theme ID is required, although variable mode does not use its palette.

```sh
comfit html main.js --theme catppuccin-mocha --style variables \
  --pre-class code-block
```

</CodeTab>
</CodeTabs>

Define colors in your CSS:

```css
.code-block {
  --comfit-fg: #cdd6f4;
  --comfit-bg: #1e1e2e;
  --comfit-keyword-fg: #cba6f7;
  --comfit-number-fg: #fab387;
}
```

Capture variables fall back from the full name to its parents, then to the default. For example, `--comfit-function-call-fg` falls back to `--comfit-function-fg`, then `--comfit-fg`. The class-prefix option does not rename these variables.

`@comfit/css` provides class rules, not variable-mode palettes. Set the variables yourself.

## Add layout styles

Use your outer class to set the font, padding, and overflow. The generated `.line` elements do not add visible line numbers. Give them `display: block` if you want selected-line backgrounds to fill the available width.

Comfit escapes source text and generated attribute values. When building your own renderer from tokens, [escape token text yourself](tokens.md#render-tokens-safely). A syntax highlighter is not a sanitizer for arbitrary HTML documents.

## Element tags

Choose the outer container and line wrapper elements. Their defaults are `pre` and `span`.

The inner `code` element and token `span` elements stay unchanged. Classes and inline styles remain on the selected wrappers.

<CodeTabs label="Element tags API">
<CodeTab label="Node.js">

```javascript
import { RenderHtmlConfig } from "@comfit/node";

const config = new RenderHtmlConfig();
config.preTag = "div";
config.lineTag = "div";
```

</CodeTab>
<CodeTab label="Browser">

Use an [initialized browser highlighter](../getting-started/browser.md) with JavaScript loaded.

```typescript
const html = highlighter.renderHtml("const answer = 42;", "javascript", {
  preTag: "div",
  lineTag: "div",
});
```

</CodeTab>
<CodeTab label="Rust">

Enable the `render-html` feature on `comfit`.

```rust
let config = comfit::RenderHtmlConfig {
    pre_tag: "div".into(),
    line_tag: "div".into(),
    ..Default::default()
};
```

</CodeTab>
<CodeTab label="Python">

```python
import comfit

config = comfit.RenderHtmlConfig(pre_tag="div", line_tag="div")
```

</CodeTab>
<CodeTab label="rehype">

Add this configuration to your framework's `rehypePlugins`. See the [Markdown and MDX](markdown.md) to set up a pipeline.

```javascript
import rehypeComfit from "@comfit/rehype";

const rehypePlugins = [
  [rehypeComfit, { preTag: "div", lineTag: "div" }],
];
```

Rehype assigns these names to its HAST wrappers after rendering, so its HTML parser does not normalize them.

</CodeTab>
<CodeTab label="Command line">

```sh
comfit html main.js --theme catppuccin-mocha \
  --pre-tag div --line-tag div
```

</CodeTab>
</CodeTabs>

> [!WARNING]
> Tag names are inserted verbatim, without validation or escaping.
>
> Use trusted container tags that fit your HTML structure. Never use untrusted input for these options.

Bundled `@comfit/css` stylesheets target `pre.comfit-<theme>`. A different outer tag needs a stylesheet with a matching selector.
