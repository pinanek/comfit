# API references

Types, functions, and methods for each Comfit package. For installation and examples, start with the [documentation](index.md).

## JavaScript

- [Node.js](api-references/javascript/node/index.md): synchronous highlighting and rendering.
- [WebAssembly](api-references/javascript/wasm/index.md): browser highlighters, documents, and rendered output.
- [rehype](api-references/javascript/rehype/index.md): code-block highlighting in Markdown pipelines.
- [markdown-it](api-references/javascript/markdown-it/index.md): fenced code-block highlighting in markdown-it pipelines.
- [WASM grammars](api-references/javascript/wasm-grammars/index.md): browser grammar assets and language definitions.

## Python

- [comfit](api-references/python/index.md): tokens, documents, HTML, and ANSI rendering.

## Rust

- [comfit](https://docs.rs/comfit/latest/comfit/): Rust highlighting with bundled or custom grammars.
- [comfit-core](https://docs.rs/comfit-core/latest/comfit_core/): the shared highlighting engine and rendering APIs.
- [comfit-grammars](https://docs.rs/comfit-grammars/latest/comfit_grammars/): bundled parsers and queries.
- [comfit-themes](https://docs.rs/comfit-themes/latest/comfit_themes/): bundled themes and VS Code theme conversion.
